# 0002. The default Windows 11 look

Date: 2026-11-08
Status: accepted

## Decision
The guide is the default Windows 11 app theme (Fluent): system font, neutral greys, the system
accent, 4px and 8px corners, layered cards, plain words. No brand colour and no decoration of
its own.

## Why
The user asked for an app theme that "abides by the default Windows 11 app theme", made the
default in Phone Explorer (its issue #3), and then for this guide to be built from that theme.
Next to Jarvis (a HUD) and Pastel Girl (very cute), this is the one that disappears into the OS.
