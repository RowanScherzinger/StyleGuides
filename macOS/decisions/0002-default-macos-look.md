# 0002. The default macOS look

Date: 2026-11-08
Status: accepted

## Decision
The guide is the default macOS app look, current release macOS 27: system font, neutral
greys, the system accent, rounded concentric shapes, Liquid Glass for the control layer, Mac
wording and button order. No brand colour and no decoration of its own.

## Why
The user asked for a macOS style guide to partner the Win11 one. Win11 is the default Windows
look, so this is the default Mac look, the one that disappears into the OS.
